# React Weather App 🌦️

A modern weather application built with React and OpenWeatherMap API that allows users to search for real-time weather information for cities around the world.

## Features
🔍 Search weather by city name
🌡️ Real-time temperature display
💧 Humidity information
🌬️ Wind speed information
🌤️ Dynamic weather icons
⚡ Fast and responsive user interface
🎨 Clean and modern design

## Tech Stack
React.js
Vite
JavaScript (ES6+)
CSS3
OpenWeatherMap API
